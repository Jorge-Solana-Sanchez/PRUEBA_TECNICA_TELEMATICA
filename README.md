# Prueba Técnica - Telemática 

Solución de los ejercicios organizada por ramas:

## Ramas del proyecto

### Ejercicios backend
- **`backend-ej1`**: API REST (GET, POST con simulación de email, PUT) con persistencia en fichero JSON.
- **`backend-ej2`**: Adaptación de la API para usar base de datos MySQL mediante Docker.

### Ejercicios frontend
- **`frontend-ej1`**: Consumo de la API de usuarios, tabla con datos principales y opción de eliminar filas.
- **`frontend-ej2`**: Modal para crear/editar usuarios conectado al backend y botón para restaurar el listado.
- **`frontend-ej3`**: Pruebas de componentes con Jest y pruebas E2E con Playwright.
